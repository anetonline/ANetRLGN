ANetRLogin v0.2.5 - Installation
=================================

FILES
-----
ANETRLGN.EXE  16-bit DOS door
ANETRLB.EXE   Win32 RLogin bridge
ANETRLV.EXE   Win32 local ANSI/CP437 viewer
ANETRLGN.CFG  OpenDoors/drop-file configuration
ANETRLGN.INI  General settings and destination allowlist

1. SHARED DIRECTORY
-------------------
Create a shared directory such as:

    C:\SF\ANETRLGN

Place at least these files there:

    ANETRLB.EXE
    ANETRLV.EXE
    ANETRLGN.INI

2. NODE-SPECIFIC DOS DOOR
-------------------------
If nodes write DOOR.SYS in different directories, give each node its own
ANETRLGN.EXE and ANETRLGN.CFG launch directory.

Example:

    C:\SF\ANETRLGN\NODE1\ANETRLGN.EXE
    C:\SF\ANETRLGN\NODE1\ANETRLGN.CFG
    C:\SF\ANETRLGN\NODE2\ANETRLGN.EXE
    C:\SF\ANETRLGN\NODE2\ANETRLGN.CFG

A-Net Online extended-door drop files:

    Node 1: C:\SF\SFEXTEN2\DOOR.SYS
    Node 2: C:\SF2\SFEXTEN2\DOOR.SYS

Node 1 ANETRLGN.CFG:

    BBSDir C:\SF\SFEXTEN2
    DoorDir C:\SF\ANETRLGN
    DisableLogging

Node 2:

    BBSDir C:\SF2\SFEXTEN2
    DoorDir C:\SF\ANETRLGN
    DisableLogging

BBSDir = directory containing that node's live DOOR.SYS.
DoorDir = SAME shared ANetRLogin IPC directory for every node.

3. CONFIGURE ANETRLGN.INI
-------------------------

    [general]
    local_viewer=1
    viewer_cols=80
    viewer_rows=25

    [destination ANETGAMES]
    name=A-Net Game Server
    host=game.a-net-online.lol
    port=513
    client_user=%PASSWORD%
    server_user=%USER%
    term=ansi/115200
    expect_ack=1
    viewer_cols=80
    viewer_rows=25

The tested Synchronet mapping is PASSWORD FIRST, USER SECOND.

viewer_cols/viewer_rows control only the local ANETRLV.EXE window. The A-Net
Game Server uses 80x25. Other destinations may override the viewer geometry if needed.

4. START THE BRIDGE
-------------------

    CD /D C:\SF\ANETRLGN
    ANETRLB.EXE

With local_viewer=1, the bridge starts a separate ANETRLV.EXE window when a
node connects. Closing that viewer does not disconnect the caller.

5. ADD BBS MENU ENTRIES
-----------------------

    Node 1:
    C:\SF\ANETRLGN\NODE1\ANETRLGN.EXE ANETGAMES

    Node 2:
    C:\SF\ANETRLGN\NODE2\ANETRLGN.EXE ANETGAMES

Use the same EXE with a different destination ID for other configured servers.

6. TEST
-------
Confirm:
- caller ANSI/CP437 looks correct;
- local viewer opens and shows the full configured width;
- normal remote exit returns to the BBS;
- ESC ESC ESC can force a manual disconnect;
- multiple nodes remain independent.

MULTI-NODE
----------
ANetRLogin supports up to 10 BBS nodes through ONE ANETRLB.EXE bridge.
Do not run one bridge per node. Node IPC files are ARL01.*, ARL02.*, etc.

PASSWORD SECURITY
-----------------
%USER%, %ALIAS%, and %PASSWORD% are available. Passwords are never shown by
the bridge/local viewer or written into viewer metadata. RLogin itself is
plaintext, so a %PASSWORD% value is transmitted unencrypted on the network.

TROUBLESHOOTING
---------------
1. Confirm ANETRLB.EXE is running.
2. Confirm the destination ID exactly matches ANETRLGN.INI.
3. Confirm host/port connectivity.
4. Confirm BBSDir points to the active node's DOOR.SYS directory.
5. Confirm every node uses the same shared DoorDir.
6. Confirm ANETRLV.EXE is beside ANETRLB.EXE when local_viewer=1.
7. For clipped viewer output, set the destination viewer_cols correctly
   (A-Net Game Server: 80) and restart ANETRLB.EXE.
8. Restart the bridge after changing ANETRLGN.INI.
