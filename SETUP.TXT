ANetRLogin v0.2.5 - Configuration
==================================

GENERAL
-------

    [general]
    local_viewer=1
    viewer_cols=80
    viewer_rows=25

local_viewer=1 automatically opens ANETRLV.EXE for active nodes.
viewer_cols/viewer_rows are defaults and may be overridden per destination.
Supported viewer geometry: 40-160 columns, 20-60 rows.

DESTINATION FORMAT
------------------

    [destination ID]
    name=Friendly Name
    host=hostname.example
    port=513
    client_user=...
    server_user=...
    term=ansi/115200
    expect_ack=1
    viewer_cols=80
    viewer_rows=25

Available caller macros:

    %USER%       BBS user name
    %ALIAS%      BBS alias / handle
    %PASSWORD%   BBS password

SYNCHRONET-COMPATIBLE LOGIN
---------------------------
Tested A-Net Game Server mapping:

    [destination ANETGAMES]
    name=A-Net Game Server
    host=game.a-net-online.lol
    port=513
    client_user=%PASSWORD%
    server_user=%USER%
    term=ansi/115200
    expect_ack=1
    viewer_cols=80
    viewer_rows=25

This is PASSWORD FIRST, USER SECOND.

ANetRLogin currently implements the plain-password case using %PASSWORD%. It
does not currently implement Synchronet's salted/hashed -h password format.

OTHER SERVERS
-------------
Different RLogin servers may repurpose RFC1282 identity fields differently.
Examples:

    client_user=%PASSWORD%
    server_user=%ALIAS%

or:

    client_user=%USER%
    server_user=%ALIAS%

The mapping is destination-specific.

MULTIPLE DESTINATIONS
---------------------
ANetRLogin supports up to 32 configured destinations. Example:

    [destination ANETGAMES]
    name=A-Net Game Server
    host=game.a-net-online.lol
    port=513
    client_user=%PASSWORD%
    server_user=%USER%
    term=ansi/115200
    expect_ack=1
    viewer_cols=80
    viewer_rows=25

    [destination OTHERBBS]
    name=Another BBS
    host=bbs.example.com
    port=513
    client_user=%USER%
    server_user=%ALIAS%
    term=ansi/115200
    expect_ack=1
    viewer_cols=80
    viewer_rows=25

Launch with:

    ANETRLGN.EXE ANETGAMES
    ANETRLGN.EXE OTHERBBS

Restart ANETRLB.EXE after changing ANETRLGN.INI.

LOCAL VIEWER
------------
ANETRLV.EXE is read-only and outside the caller path. The bridge mirrors
incoming bytes to ARLnn.VWR and safe metadata to ARLnn.VMI. Passwords are
never written to viewer metadata.

v0.2.5 supports configurable column modes and sizes the Win32 viewer from the
actual Terminal font metrics so the configured right edge remains visible.

MULTI-NODE
----------
Up to 10 nodes share one bridge. Each node's BBSDir points to its own live
DOOR.SYS location while every node uses the same shared DoorDir.

A-Net examples:

    Node 1:
        BBSDir C:\SF\SFEXTEN2
        DoorDir C:\SF\ANETRLGN

    Node 2:
        BBSDir C:\SF2\SFEXTEN2
        DoorDir C:\SF\ANETRLGN

Node files:
    ARL01.* Node 1
    ARL02.* Node 2
    ...
    ARL10.* Node 10

Two simultaneous Spitfire nodes have been live-tested successfully through a
single bridge.

SECURITY
--------
The destination ID is an allowlist key. Callers do not supply arbitrary hosts
or ports. The bridge/local viewer must never display/log expanded %PASSWORD%.
RLogin is plaintext; use trusted/private/VPN paths where practical.
